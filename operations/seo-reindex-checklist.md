# 검색 재등록 체크리스트

## 대상

- 현재 공개 URL: `https://jiggyj744-ctrl.github.io/`
- sitemap: `https://jiggyj744-ctrl.github.io/sitemap.xml`
- robots: `https://jiggyj744-ctrl.github.io/robots.txt`

## 사전 확인

- 홈 title에 `지분경매·공유물 지분 매입 상담`이 포함됩니다.
- 공개 HTML에 과거 브랜드와 이전 웹마스터 인증 파일이 없습니다.
- sitemap이 `github.io` 기준 URL만 포함합니다.
- robots.txt가 sitemap을 가리킵니다.
- 모바일에서 가로 스크롤이 없습니다.

## Google Search Console

1. `https://jiggyj744-ctrl.github.io/` URL-prefix 속성을 추가합니다.
2. 필요한 경우 새 소유권 확인 파일만 별도 커밋으로 추가합니다.
3. `sitemap.xml`을 제출합니다.
4. 루트 URL 색인 생성 요청을 수행합니다.
5. URL 검사에서 canonical, robots, 모바일 사용성을 확인합니다.

## Naver Search Advisor

1. 사이트를 새로 등록합니다.
2. 필요한 경우 새 소유권 확인 파일만 별도 커밋으로 추가합니다.
3. sitemap과 robots.txt를 제출합니다.
4. 웹 페이지 수집 요청에 루트 URL을 등록합니다.

## 커스텀 도메인 연결 후

도메인을 연결하면 sitemap, canonical, robots의 기준 URL을 새 도메인으로 바꾼 뒤 다시 제출합니다.
