# 워드프레스 제작 체크리스트

## 기본 구성

- WordPress 별도 호스팅 사용
- SSL 적용
- 이 저장소의 `theme/share-auction-landing/` 테마 업로드
- SEO 플러그인 설치
- 백업 플러그인 또는 서버 스냅샷 설정

## 테마 업로드

1. `share-auction-landing.zip`을 워드프레스 관리자 화면의 `외모 > 테마 > 새로 추가 > 테마 업로드`에서 업로드한다.
2. 테마를 활성화한다.
3. `설정 > 일반`의 관리자 이메일을 상담 접수 수신 이메일로 맞춘다.
4. SMTP 플러그인을 설치해 `wp_mail()` 발송을 검증한다.
5. 사이트 제목과 연락처가 확정되면 `front-page.php`의 전화번호를 실제 운영번호로 맞춘다.

## 필수 페이지

- 메인 랜딩: 테마 `front-page.php`
- 상담 접수: 메인 랜딩 내 폼
- 개인정보처리방침: WordPress 기본 개인정보 페이지 생성
- 상담 유의사항: 고정 페이지로 별도 생성
- 404 페이지: 운영 전 추가 권장

## 필수 전환 요소

- 전화 상담 버튼
- 카카오 상담 버튼
- 사건번호/주소 기반 검토 요청 폼
- 모바일 하단 고정 CTA
- 폼 제출 알림

## 색인 전환

- 기존 GitHub sitemap/feed는 사용하지 않음
- 새 WordPress sitemap만 제출
- 기존 대량 URL은 목적에 따라 404, 410, 또는 새 콘텐츠로 301 처리
- 삭제 요청만으로 영구 제거가 끝났다고 보지 않음
