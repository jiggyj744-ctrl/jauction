# GitHub Pages 지분매입 랜딩 운영 기획

작성일: 2026-06-30

## 목표

공유물 지분을 보유했지만 매각이 어렵거나, 지분경매 사건을 검토 중이거나, 상속 지분을 정리하려는 사용자를 유입해 1차 자료를 받고 매입 가능성 검토로 연결합니다.

## 핵심 포지션

- 일반 경매정보 포털이 아니라 공유지분 문제 해결형 상담 사이트입니다.
- 물건 검색보다 상담 전환을 우선합니다.
- 무조건 매입, 최고가 보장, 즉시 현금화 같은 표현은 사용하지 않습니다.
- 등기, 사건번호, 지분율, 공유자 수, 점유 상태를 보고 매입 가능성·보류 사유·추가 자료를 나눠 안내합니다.

## 고객 유형

| 고객 | 문제 | 랜딩 메시지 |
|---|---|---|
| 상속 지분 보유자 | 가족 공동명의가 오래 지속됨 | 상속 지분의 매입 가능성과 정리 방향을 확인 |
| 공동명의 부동산 보유자 | 공유자 협의가 되지 않음 | 협의, 공동매각, 직접 매입 가능성 분리 |
| 지분경매 입찰 예정자 | 우선매수권과 낙찰 후 정리가 불확실 | 입찰 전 리스크와 철수 기준 확인 |
| 지분경매 낙찰자 | 낙찰 후 공유자 협의가 막힘 | 낙찰 후 협의·분할·매각 방향 검토 |
| 토지 지분 보유자 | 맹지, 도로, 개발 제한으로 처분 곤란 | 토지 특성 반영 후 매입 가능성 검토 |

## 사이트 구조

- `/`: 메인 랜딩
- `/services/share-purchase/`: 공유물 지분 매입
- `/services/share-auction/`: 지분경매 낙찰 전후 검토
- `/services/inherited-share/`: 상속 지분 정리
- `/services/land-share/`: 토지 지분 매입
- `/services/co-ownership-dispute/`: 공유자 갈등 및 공유물분할
- `/services/commercial-share/`: 상가·건물 지분 검토
- `/faq/`: FAQ
- `/privacy/`: 개인정보 처리방침

## 첫 화면 기준

- H1: `팔기 어려운 공유물 지분, 검토 후 매입 가능성을 제안합니다`
- 보조문: 공유자 합의, 상속 지분, 지분경매 낙찰 전후 사건을 등기와 사건자료 기준으로 확인
- CTA: `내 지분 검토 요청`, 전화 상담
- 신뢰 문구: 등기부·사건자료·점유 상태, 아파트·토지·상가·건물, 자료 확인 후 매입 조건 제안

## 리드 저장 확장안

1. 즉시 운영: 전화·문자 fallback
2. 단기 개선: Google Apps Script로 Google Sheets 저장
3. 권장 운영: Cloudflare Workers로 접수 API 구성
4. 장기 운영: 관리자 CRM 또는 WordPress/API 백엔드와 연결
