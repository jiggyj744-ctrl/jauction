## 3. 새 사이트 포지셔닝

### 한 줄 정의

지분경매·공유물 지분 매입 전문 상담 사이트.

### 핵심 고객

| 고객 유형 | 현재 문제 | 랜딩에서 잡아야 할 메시지 |
|---|---|---|
| 상속으로 지분을 받은 사람 | 지분만 있어 사용도 매각도 어렵다 | “공유자 동의가 어려운 지분도 매입 가능성을 검토합니다” |
| 공동명의 부동산을 정리하려는 사람 | 공동소유자와 협의가 안 된다 | “협의, 매입, 공유물분할 가능성을 함께 검토합니다” |
| 지분경매 입찰 예정자 | 우선매수권, 점유, 분할 가능성이 불확실하다 | “입찰 전 지분 리스크와 회수 전략을 점검합니다” |
| 지분경매 낙찰자 | 낙찰 후 공유자 협의, 명도, 처분이 막혔다 | “낙찰 후 지분 정리와 매각 전략을 검토합니다” |
| 토지 지분 보유자 | 맹지, 농지취득자격, 도로 문제로 처분이 어렵다 | “토지 지분은 진입로, 농지, 공유자 수를 먼저 봅니다” |

### 핵심 차별점

1. 일반 경매정보 포털이 아니라 지분만 다룬다.
2. 검색보다 상담 전환을 우선한다.
3. “얼마에 살 수 있다”가 아니라 “등기·지분율·현장·권리관계 확인 후 매입 가능성과 범위를 제안”한다.
4. 법률·세무 확정 자문이 아니라 매입 검토와 실무 정리 중심으로 표현한다.

### 5-3. 문제 공감 섹션

제목:

> 지분 부동산은 “시세”보다 “정리 가능성”이 먼저입니다

카드 6개:

1. 지분만 있어 단독 사용이 어렵다
2. 공유자와 연락 또는 협의가 안 된다
3. 상속지분이라 가족 간 분쟁이 있다
4. 지분경매 입찰 후 공유자 우선매수권이 걱정된다
5. 토지 지분인데 도로, 농지, 맹지 문제가 있다
6. 공유물분할 경매로 넘어갈 가능성이 있다

각 카드에는 짧은 설명과 “검토 필요 서류”를 붙인다.

예:

> 공유자가 많을수록 매입가보다 협의 구조가 중요합니다. 등기부, 지분율, 점유 관계를 먼저 확인해야 합니다.

   - 제안: 직접 매입 또는 공동매각 협의

2. 토지 1/8 지분과 맹지 문제
   - 문제: 단독 이용 불가, 진입로 불명확
   - 검토: 도로 접면, 지목, 농지취득자격, 개발 가능성
   - 제안: 지분 매입가 범위와 장기 회수 가능성 검토

3. 지분경매 입찰 전 사건
   - 문제: 최저가가 낮아 보여도 공유자 우선매수권이 존재
   - 검토: 공유자 수, 우선매수 가능성, 낙찰 후 출구
   - 제안: 입찰가 상한과 철수 기준 설정

4. 낙찰 후 공유자 협의가 막힌 지분
   - 문제: 공유자가 매수도 매도도 거부
   - 검토: 공유물분할 가능성, 협의 구조, 보유 비용
   - 제안: 협상안 또는 매입/재매각 전략 검토

5. 상가 지분과 임차인 문제
   - 문제: 임대차, 관리비, 수익 배분이 불명확
   - 검토: 임차인 대항력, 보증금, 수익성, 관리 상태
   - 제안: 실수익 기준의 지분가치 산정

6. 공유물분할을 위한 경매
   - 문제: 일반 강제경매와 성격이 다름
   - 검토: 분할 청구 배경, 현물분할 가능성, 경매 이후 배분
   - 제안: 입찰 또는 매입 여부 판단

### 5-11. FAQ 섹션

FAQ 초안:

1. 공유자 동의 없이 제 지분만 팔 수 있나요?
   - 원칙적으로 자기 지분은 처분할 수 있으나, 실제 매입 가능성과 가격은 지분율, 점유, 권리관계, 공유자 수에 따라 달라집니다.

2. 지분만 있으면 가격이 많이 낮아지나요?
   - 단순 지분율만으로 결정되지 않습니다. 단독 이용 가능성, 공유자 협의 가능성, 분할 가능성, 현장 상태가 함께 반영됩니다.

3. 사건번호만 있어도 상담 가능한가요?
   - 가능합니다. 사건번호, 법원명, 매각기일이 있으면 1차 검토를 시작할 수 있습니다. 필요 시 등기부와 매각물건명세서를 추가 확인합니다.

4. 공유자 우선매수권이 있으면 입찰하면 안 되나요?
   - 무조건 입찰 불가라는 뜻은 아닙니다. 다만 입찰가 상한, 공유자 가능성, 차순위 지위, 낙찰 후 전략을 먼저 검토해야 합니다.

5. 토지 지분도 매입하나요?
   - 검토 가능합니다. 토지는 도로, 지목, 농지취득자격, 맹지, 분묘, 개발 제한에 따라 매입 가능성이 달라집니다.

6. 상담 후 꼭 매각해야 하나요?
   - 아닙니다. 매입 가능성, 예상 가격 범위, 다른 정리 방법을 확인한 뒤 결정할 수 있습니다.

7. 법률 상담도 해주나요?
   - 매입과 실무 검토 중심으로 상담하며, 소송·세금·등기 등 전문 판단이 필요한 부분은 변호사, 세무사, 법무사 확인이 필요할 수 있습니다.

8. 얼마나 빨리 검토되나요?
   - 사건번호와 기본 자료가 있으면 1차 검토는 빠르게 가능하지만, 권리관계와 현장 확인이 필요한 경우 시간이 더 걸릴 수 있습니다.

## 8. SEO 및 색인 전환 계획

### 기존 GitHub/색인 처리 원칙

Google Search Console 삭제 도구는 검색결과에서 일시적으로 차단하는 도구이며, 영구 삭제를 보장하지 않는다. Google 공식 문서 기준으로 영구 삭제를 하려면 콘텐츠 삭제 후 404/410 반환, 접근 차단, 또는 noindex 같은 후속 조치가 필요하다. robots.txt를 영구 삭제 수단으로 쓰는 방식은 적절하지 않다.

따라서 새 사이트 전환 시 원칙은 다음이다.

1. 기존 GitHub Pages의 대량 HTML, sitemap, RSS, verification 파일을 공개 상태로 계속 두지 않는다.
2. 새 워드프레스가 같은 도메인을 쓴다면 기존 URL은 목적에 따라 301, 404, 410에 준하는 처리 중 하나로 분류한다.
3. 새 워드프레스가 다른 도메인을 쓴다면 기존 GitHub Pages는 비활성화하거나 비공개 전환한다.
4. 삭제 요청만 해놓고 기존 파일을 계속 공개하면 검색엔진이 다시 발견할 수 있다.
5. old sitemap/feed 제출 이력은 정리하고, 새 사이트 sitemap만 제출한다.

### 기존 URL 처리 기준

| 기존 URL 유형 | 처리 |
|---|---|
| `/auction/*.html` 대량 경매 상세 | 새 사이트와 주제가 다르면 404로 정리 |
| `/guide/`, `/dictionary/`, `/faq/` | 새 지분경매 콘텐츠로 재작성할 경우 301 또는 동일 slug 재사용 |
| `/about/`, `/privacy/`, `/terms/` | 새 워드프레스 페이지로 교체 |
| `feed.xml`, `sitemap*.xml` | 기존 파일 삭제 후 새 WP sitemap으로 교체 |
| Google/Naver verification 파일 | 더 이상 사용하지 않으면 삭제 |
| `docs-bid` | 새 사이트와 충돌하면 삭제 또는 비공개 |

- 첨부파일 접근권한 확인
- 개인정보처리방침 연결 확인
- 404/redirect 확인
- sitemap/robots 확인
- 페이지 속도 확인
- 검색엔진에 이전 URL이 재노출될 구조가 남아 있는지 확인

## 13. 최종 운영 방향

이 사이트는 기존의 “전국 경매물건을 많이 보여주는 사이트”가 아니라 “복잡한 지분 문제를 상담으로 전환하는 사이트”로 가야 한다.  
따라서 첫 버전에서 중요한 것은 물건 수, 검색 기능, 대량 색인이 아니라 다음 4가지다.

1. 사용자가 자기 문제라고 느끼는 히어로 문구
2. 사건번호/주소/지분율을 받는 상담 폼
3. 지분경매 리스크를 전문적으로 설명하는 섹션
4. 전화·카카오·폼 전환을 놓치지 않는 모바일 CTA
